# Typography

Two typefaces, shared with the product — **never** substitute. **Besley** (serif) carries display +
all headings and is where the warm, editorial, kept-object feeling lives. **Geist** (sans) carries
body, UI, and labels; **Geist Mono** carries code.

The product display tops out at 40px. Marketing **adds** a fluid, editorial tier on top — pushing the

> **When to use which:** product-embedded UI inside a marketing page (e.g. a `ShowcaseFrame` mock,
> `MessageBubble`, `StatCard`) uses the **inherited KDS ramp** so it reads as the real product.
> Marketing *chrome* around it — heroes, section heads, leads — uses the **marketing tier**. Don't mix:
> a marketing hero never uses `--font-size-display`, and a product mock never uses `--text-hero`.

## Rules (from souvenir-learnings §2)

- **Fluid `clamp()` sizing** for marketing, never per-breakpoint; the product ramp stays fixed px.
- Every size comes from a token — **never free-set** a font size.
- **Measure ~65ch** (`--measure`); **`text-wrap: balance`** on headings; **no widows**.
- **Tabular nums** on anything numeric. **Hero capped at 96px** — generous but restrained.
- Let **Besley carry the emotion** — one big serif line beats a busy stack.

> **Tailwind v4 gotcha:** an arbitrary color set as a bare CSS-var (the bracket-var form) is dropped
> silently — use a semantic utility or type the arbitrary value with the `color:` prefix; font sizes
> need the `length:` prefix. (Examples live in the `souvenir-taste` skill so Storybook's markdown
> isn't scanned as real classes.)
