# Motion

Marketing motion is **slower and more deliberate** than product UI — nostalgia is unhurried. The point
is *arrival*: content **assembles into place** (as if placed), it doesn't just flash in. Full rules:
`docs/souvenir-learnings.md` §1 + the `motion-and-easing` skill.

## The gate (animate only if you can name the purpose)

1. **Purpose** — orient, give feedback, show a relationship, or *rare* delight. No decoration.
2. **Frequency** — the more often a user sees it, the shorter/subtler. Never animate
   frequently-repeated keyboard actions.
3. **Speed** — UI < 300ms, hover ~150ms. Marketing signature moments get latitude (up to ~1.1s).

## Duration tiers

| Token | Value | Use |
|---|---|---|
| `--dur-hover` | .15s | hover color / opacity |
| `--dur-fast` | .25s | UI tier (keep < 300ms) |
| `--dur` | .5s | default marketing transition |
| `--dur-slow` | .8s | larger reveals |
| `--dur-signature` | 1.1s | the **one** signature moment per page |

## Easing — a lookup, not a vibe

| Token | Curve | Use |
|---|---|---|
| `--ease-out` | `cubic-bezier(0.16,1,0.3,1)` | enter / exit — fast start = responsive |
| `--ease-in-out` | `cubic-bezier(0.65,0,0.35,1)` | element already on screen moving / morphing |
| _ease-in_ | — | **avoid** — slow start feels sluggish |
| _linear_ | — | only marquees / spinners / time-fills |

## Rules

- **Enter ≠ exit.** Enter decelerates into place (arrival); exit accelerates away. Don't just reverse.
- **Stagger ~40ms** (`--stagger`) between items for a sense of arrival — all-at-once reads as a flash.
- **No bounce / spring.** The only sanctioned spring is the inherited KDS in-place text-swap.
- **Animate `transform` + `opacity` only** (GPU-composited). Width/height/top/left = jank.
- **Always** honor `prefers-reduced-motion` — render static, no transform.
- **One signature moment per page.** Lock layout + type *before* adding motion.

The site's single entrance primitive is **`<Reveal>`** (fade + 24px rise, once, `power3.out`,
reduced-motion safe). See it under **Primitives → Reveal**.
