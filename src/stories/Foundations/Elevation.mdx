# Elevation & Depth

Depth here is **tactile, not floaty**. Souvenir should feel like a real, kept object — so shadows are
**warm-tinted** (toward espresso, never neutral grey or blue) and paired with an **emboss** (a top
inner highlight + bottom inner line) so surfaces read as *pressed/printed*, not hovering in space.

## The emboss (what makes it feel printed)

`--shadow-inner` = `inset 0 1px 0 rgba(255,255,255,.75)` (top highlight) + `inset 0 -1.5px 0 rgba(82,75,71,.07)`
(bottom warm line). Layer it *over* a surface's outer shadow. This is the single most identity-bearing
depth move — the vendored Kaya Button and `ShowcaseFrame` both use it.

## Rules

- **Warm shadows only.** All shadow tokens are tinted with `rgba(82,75,71,…)` (espresso), never grey/blue.
- **Press = `scale(0.97)`** (vendored Button uses `0.98`) — physical feedback, ~150ms.
- **Squircle**, not a plain border-radius, on the hero CTA + framed surfaces (figma-squircle / the Kaya
  Button's `useSquircle`) — the corner curvature is part of the tactile signature.
- **Heavy craft is hero-only** (layered shadows / grain) — it's an LCP/perf cost; don't sprinkle it.
- **Every surface earns its elevation** — if it doesn't lift on purpose, keep it flat on the canvas.
