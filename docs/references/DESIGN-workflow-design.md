## 1. Visual Theme & Atmosphere
"Approachable professionalism" — friendly yet sophisticated, human-centered, trustworthy. Calm,
premium, content-first. Real avatars + conversational UI examples create relatability.

## 2. Color Palette & Roles
- Canvas: white / near-white dominates.
- Ink: charcoal / dark gray for primary text.
- Neutrals: soft grays for secondary UI + borders.
- Functional: subtle blue/teal for interactive states; red/orange for alerts/feedback.
- Restrained, content-clarity-first.

## 3. Typography Rules
Contemporary geometric sans. Hierarchy via weight (bold/semibold headings, regular body) and a fluid
scale from compact labels to large hero headlines.

## 4. Component Stylings
Pill-shaped buttons with subtle shadows; comment threads with avatars + timestamps; version-comparison
cards (iterative work); testimonial blocks with real portraits; video/motion playback controls.

## 5. Layout Principles
Grid-based, clean columns, generous whitespace. Asymmetric balance (text paired with UI mockups).
Discrete card modules with consistent spacing. Full-width hero with stacked text + imagery.

## 6. Depth & Elevation
Subtle shadows on contained modules/cards; otherwise flat. ~16–32px spacing increments.

## 7. Do's & Don'ts
- ✅ Generous whitespace; real avatars/portraits; restrained palette; contained card modules.
- ❌ Cramped layouts; heavy color; decorative noise.

## 8. Responsive Behavior
Implied standard grid collapse; cards stack. (Unverified — needs the screenshot.)

## 9. Agent Prompt Guide
"White canvas, charcoal text, soft-gray neutrals, one subtle blue/teal interactive accent. Geometric
sans with weight-based hierarchy. Pill buttons with subtle shadow, contained card modules, generous
whitespace, real avatars in conversational/comment examples. Calm, premium, human-centered."
