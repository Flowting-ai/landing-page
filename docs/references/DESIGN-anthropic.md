# DESIGN.md — Anthropic (reference only)

> Reference teardown to study **structure & restraint**, NOT to copy. Source: `.refs/anthropic.png`
> + general knowledge. Borrow the mechanic (warm-neutral editorial gravitas), not the content.

## 1. Visual Theme & Atmosphere
Warm, literary, institutional-but-human. "Safety at the frontier" gravitas. Reads like a thoughtful
publication, not a SaaS app. Calm, considered, confident. Sparse — lets type + one big image carry it.

## 2. Color Palette & Roles
- Canvas: warm bone/cream (~`#F0EDE6`–`#FAF9F5`).
- Ink: near-black warm (~`#191917`).
- Feature blocks: deep charcoal (~`#1A1A18`) full-bleed, with generative mesh/line art.
- Accent: essentially none — occasional clay/rust. **Color is rationed; warmth comes from the neutral.**

## 3. Typography Rules
- Humanist grotesque sans (Styrene-like) for nav, hero, body.
- A **serif** (Tiempos/Copernicus-like) for large feature display ("Project Glasswing") — the gravitas move.
- Hero **underlines keywords** ("research", "products") for emphasis instead of color.
- Confident, tight, large headline weights.

## 4. Component Stylings
Dark pill primary ("Try Claude"); plain text nav with carets; underlined inline keywords; large
full-bleed image/art blocks. Minimal chrome.

## 5. Layout Principles
Asymmetric hero (big left headline + small right paragraph). Full-bleed dark feature blocks alternate
with light canvas. Generous margins; few elements per view.

## 6. Depth & Elevation
Mostly flat. Depth = contrast of large dark image blocks against the light canvas, not shadows.

## 7. Do's & Don'ts
- ✅ Warm-neutral restraint; serif for emotional/gravitas moments; underline > color for emphasis.
- ❌ Gradients, glow, bright accents, busy layouts, multiple competing focal points.

## 8. Responsive Behavior
Hero stacks (headline over paragraph); feature blocks go full-width; margins tighten.

## 9. Agent Prompt Guide
"Warm bone canvas, near-black warm ink, humanist grotesque sans with an occasional serif display for
gravitas, underline keywords instead of coloring them, ration color to near-zero, alternate light
canvas with full-bleed dark editorial image blocks. Institutional calm, one idea per screen."
