# Query GA with Scout

Ask the Souvenir Scout agent for your Google Analytics numbers in plain language — no dashboards required.

Interactive demo: https://app.supademo.com/demo/cmqynsc011yb1qmec1r8ek0ir

## 1. To get started, click the Chats tab to view your conversation history and active discussions.

## 2. Click here to add an agent to your chat at any time.

## 3. From here, click Add agent to bring a new agent into your workspace.

## 4. Select any agent from your library to add it to the chat.

## 5. Afterwards, click in the message input field and enter your question for Souvenir Scout.

## 6. Then, enter your query in the message box to request data from Google Analytics.

## 7. Then, click the Send button to submit your message and run the agent request.
